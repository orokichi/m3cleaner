# M3 Cleaner

Groq Console API を使って、使用頻度の低いアプリと長く開いていないファイルを提案し、まとめてアンインストール・消去できる Android アプリ。

## 機能
- **AI提案**: アプリの最終使用日・使用時間・容量、ファイルの容量・最終閲覧日を Groq (llama-3.3-70b など) が分析し、削除候補を理由付きで提案
- **アプリ**: 全ユーザーアプリを未使用順/容量順/名前順で表示、複数選択して連続アンインストール
- **ファイル**: 内部ストレージ全体から指定サイズ以上のファイルを検索、容量順/未閲覧順、タップで開く、選択して消去
- **ストレージ**: 使用量・空き容量を表示
- Material 3 / ダイナミックカラー / ダークモード

## 権限
| 権限 | 用途 |
|---|---|
| PACKAGE_USAGE_STATS | アプリの使用状況・容量の取得 |
| QUERY_ALL_PACKAGES | 全アプリの一覧取得 |
| REQUEST_DELETE_PACKAGES | アンインストール要求（1件ずつAndroidの確認画面が出ます） |
| MANAGE_EXTERNAL_STORAGE | 全ファイルの検索・消去 |
| INTERNET | Groq API |

> Androidの仕様上、root やデバイスオーナーでない一般アプリは確認なしにアンインストールできません。プリインストールのシステムアプリは対象外です。

## プライバシー
APIキーは端末内のみに保存。Groqへはアプリ名・パッケージ名・日数・容量・ファイル名/フォルダ名だけを送信し、ファイルの中身は送りません。

## ビルド
`main` への push で GitHub Actions が署名済み APK をビルドし、Releases に公開します。
